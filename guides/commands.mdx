Reference for **[doubt-bot](https://github.com/Doubt-Productions/doubt-bot)** slash commands. Commands are discovered via discordx decorators under `src/commands/categories/` and registered on guild ready with `bot.initApplicationCommands()`.

<Note>
Several management commands require **Manage Server** or other Discord permissions. Guards enforce checks at runtime. See [Security](/security).
</Note>

## Economy

| Command | Description | Notes |
|---------|-------------|-------|
| `/economy` | Create or delete your economy account | Buttons: Create / Delete |
| `/bal` | Wallet, bank, and total balance | Requires account |
| `/deposit amount` | Move wallet → bank | `amount` or `all` |
| `/withdraw amount` | Move bank → wallet | `amount` or `all` |
| `/beg` | Random wallet change | Requires account |
| `/rob user` | Attempt to rob another user | Both need ≥ $100 wallet; cooldown applies |

New accounts: **$0 wallet**, **$1000 bank** (`EconomyAccount` in Postgres).

## General

| Command | Description |
|---------|-------------|
| `/afk set [message]` | Set AFK; prefixes nickname with `[AFK]` |
| `/afk remove` | Clear AFK and restore nickname |
| `/rank info [user]` | Rank embed (level + XP) |
| `/rank reset user` | Reset XP (Manage Server) |
| `/rank set user level` | Set level (Manage Server) |
| `/rank leaderboard` | Top 10 by XP in this guild |

## Utility

## Management

| Command | Description | Gate |
|---------|-------------|------|
| `/setup` | Configure welcome, tickets, join-to-create | Manage Server |

Setup uses select menus, channel/role pickers, and **modals** (welcome message, ticket reason).

## Administration

### `/badge` (StaffOnly — BotStaff or developer)

| Subcommand | Description |
|------------|-------------|
| `create key display_name [emoji]` | Create a non-reserved badge |
| `update key display_name [emoji]` | Update badge metadata |
| `delete key` | Delete a non-reserved badge |
| `list` | List all badge definitions |
| `user discord_id` | List badges granted to a user |

Reserved key **`bot-staff`** cannot be managed here. There is no `give`/`take` subcommand — staff badges sync from **`/botstaff`**.

### `/botstaff` (DeveloperOnly)

| Subcommand | Description |
|------------|-------------|
| `add user` | Insert `BotStaff` row; sync 🛡️ badge |
| `remove user` | Remove staff; strip badge; audit removal |
| `list` | Staff roster with `addedBy` / `addedAt` |
| `migrate` | Re-sync 🛡️ badge for **all existing** `BotStaff` rows |

<Warning>
**`/botstaff migrate` is not** the legacy JS import from `moderation.staffRoles`. For cutover from Mongo/legacy config, use **`yarn migrate:mongo`** and/or manual **`/botstaff add`**. Apply **`yarn prisma:migrate:deploy`** before any BotStaff writes.
</Warning>

<Tip>
The `bot-staff` badge is display-only. Privilege comes from the **`BotStaff` Postgres table**, not from holding the badge.
</Tip>

## Legacy bot only (until ported to doubt-bot)

The following remain on **[Doubt-Discord-Bot](https://github.com/Doubt-Productions/Doubt-Discord-Bot)** until cutover. Do not expect them on doubt-bot today:

### Moderation

`/kick`, `/ban`, `/unban`, `/timeout`, `/automod` (subcommands)

### Utility / info (legacy shapes)

`/embedcreator`, `/botinfo`, `/serverinfo`, `/test`

### Context menus

User: **Info**, **Profile**, **Get Avatar** — Message: **Translate Message**

### Developer (legacy `devOnly/` guild)

`/eval`, `/deploy`, `/connectdb`, `/simjoin`, `/simleave`, `/listguilds`, `/staffonly`, `/nsfw`, `/testembed`, legacy `/badge give|take`, legacy `/botstaff migrate` from `staffRoles`

When doubt-bot reaches parity, this section will shrink — track the private repo and these docs for updates.
