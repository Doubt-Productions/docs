Feature behavior for the TypeScript bot (**[doubt-bot](https://github.com/Doubt-Productions/doubt-bot)**). Data is stored in **PostgreSQL** unless noted. Legacy Mongo collections on [Doubt-Discord-Bot](https://github.com/Doubt-Productions/Doubt-Discord-Bot) are migrated with `yarn migrate:mongo`.

## Economy System

Virtual currency per guild member (`EconomyAccount`: `guildId`, `discordId`, `wallet`, `bank`).

### Getting started

1. Run `/economy` and click **Create**.
2. Defaults: **$0 wallet**, **$1000 bank**.
3. Use `/bal` anytime.

### Commands

- **`/deposit`**, **`/withdraw`** — `all` supported (case-insensitive).
- **`/beg`** — random wallet adjustment.
- **`/rob`** — both users need accounts and ≥ $100 wallet; cooldown and penalty rules apply.
- **`/economy` → Delete** — removes the Postgres row.

## Ticket System

Configured via `/setup` → ticket flow (`Setup` model: category, panel channel, staff role).

### Flow

1. Member picks a subject on the ticket panel select menu.
2. A **modal** collects the reason (`ticket-modal`).
3. A private channel `ticket-<displayName>` is created with permission overwrites for the opener, bot, and staff role.
4. **Close Ticket** button runs authorization (see [Security](/security#ticket-close-authorization)).
5. The opener receives a DM embed; the channel deletes after 10 seconds.

<Note>
The TypeScript port does not generate HTML transcripts in-channel; closure notifies via DM embed. Legacy HTML transcripts remain on Doubt-Discord-Bot until ported.
</Note>

## Welcome System

Per-guild configuration (`WelcomeConfig` table) — not limited to a single support guild.

### Setup

1. `/setup` → Welcome options.
2. Set channel, rules channel, member/bot roles via select menus.
3. Set the message template via a **modal** (`welcome-message-modal`) — placeholders `{user}`, `{rules}`, `{server}`.

### On join

`guildMemberAdd` loads config, sends the formatted message, and assigns member or bot role when configured.

## AFK System

Stored in `Afk` (`guildId`, `discordId`, `reason`, stored nickname).

- **`/afk set [message]`** — sets DB row and `[AFK]` nickname prefix.
- **`/afk remove`** — clears row and restores nickname.
- **`messageCreate`** — clears AFK when the author sends a message; notifies when someone **mentions** an AFK user (no Message Content Intent).

---

## Join-to-Create (JTC)

Configured in `/setup` (`JtcSetup`, `JtcChannel` models).

1. Admin sets hub channel and category.
2. Joining the hub creates a temporary voice channel; owner gets manage permissions.
3. `voiceStateUpdate` handles transfer/delete when the owner leaves.

## Rank / XP System

`Xp` rows link to `User` records (`amount`, `level` per guild).

- **`/rank info`** — embed with level and XP.
- **`/rank leaderboard`** — top ten in guild.
- **`/rank reset`**, **`/rank set`** — Manage Server.

Legacy Canvacord image cards from Doubt-Discord-Bot are not used in doubt-bot.

## Badge System

Normalized Postgres models: `Badge`, `User`, `UserBadge`.

### Administration (staff or developer)

- **`/badge create|update|delete|list|user`** — see [Commands](/guides/commands#badge-staffonly--botstaff-or-developer).

<Warning>
**`bot-staff`** is reserved. `/badge` blocks reserved keys and lookalikes. Use **`/botstaff`** for staff roster changes.
</Warning>

### Display

Badges appear on user-facing commands as they are wired (profile/info paths evolve with ports).

## Global Bot Staff

Postgres `BotStaff` replaces legacy `config.moderation.staffRoles`.

1. Developer runs **`/botstaff add`** → row + badge sync.
2. **`StaffOnly`** commands check `BotStaff` or developer IDs.
3. **`/botstaff remove`** → removal audit + badge strip.
4. **`/botstaff migrate`** → badge re-sync for existing rows only.

### Cutover from legacy Mongo / JS bot

<Warning>
Run **`yarn prisma:migrate:deploy`** before importing staff. Do not rely on an empty ACL during cutover.
</Warning>

1. Deploy doubt-bot with current migrations applied.
2. Run **`yarn migrate:mongo`** (includes BotStaff) **or** add each member with **`/botstaff add`**.
3. **`/botstaff migrate`** for badge sync if needed.
4. **`/botstaff list`** to verify.

Legacy **`/botstaff migrate`** on Doubt-Discord-Bot (from `staffRoles`) applies only on the JS bot before data export.

See [Configuration](/get-started/configuration#global-bot-staff) and [Security](/security#global-bot-staff-acl).

## Moderation (legacy until port)

Kick, ban, timeout, and automod live on **Doubt-Discord-Bot** today. doubt-bot `Setup` includes automod-related fields for future use; slash moderation commands are not registered yet.

---

## Health / uptime

The TypeScript bot does **not** expose the legacy Express `:8080` health server. Use your process manager, Docker healthchecks, or Discord connectivity for monitoring.

---

## Help menu

`/help` builds categories from discordx `@Category()` metadata and restricts select-menu use to the command invoker (same pattern as legacy help ownership).
