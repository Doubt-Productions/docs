Doubt is a multi-purpose Discord bot for moderation, economy, tickets, welcome flows, AFK, join-to-create voice, and leveling. The **active rewrite** lives in the private repository [Doubt-Productions/doubt-bot](https://github.com/Doubt-Productions/doubt-bot): TypeScript, [discordx](https://discordx.js.org/), [discord.js v14](https://discord.js.org/), [Prisma](https://www.prisma.io/) on **PostgreSQL**, [Biome](https://biomejs.dev/), ESM, Docker, and Yarn.

The legacy JavaScript bot ([Doubt-Discord-Bot](https://github.com/Doubt-Productions/Doubt-Discord-Bot)) remains in production until cutover. These docs describe the **TypeScript stack as the current target**; where a feature is not ported yet, guides call that out.

Commands are **slash-only** (plus buttons, select menus, and modals). The bot does **not** use Discord's Message Content Intent and does **not** support prefix commands.

## Features

- **Moderation** — kick, ban, timeout, automod *(legacy bot today; port in progress on doubt-bot)*
- **Economy** — wallet/bank accounts, begging, deposits, withdrawals, robbery
- **Tickets** — configurable panels, modal-based opening, staff roles, close authorization
- **Welcome** — per-guild join messages, auto-roles, welcome message via **modal** (not message collectors)
- **AFK** — nickname prefix and mention notifications without reading message content
- **Join-to-Create** — temporary voice channels from a hub channel
- **Rank / XP** — per-guild XP, leaderboard, rank embeds
- **Badges & BotStaff** — Postgres-backed badges; global staff ACL with display-only `bot-staff` badge
- **Administration** — `/botstaff` (developer-gated), `/badge` (bot staff or developers)

## Tech stack (doubt-bot)

| Component | Technology |
|-----------|------------|
| Runtime | Node.js 18+ |
| Language | TypeScript (ESM) |
| Bot framework | discordx + discord.js v14 |
| Database | PostgreSQL via Prisma 6 |
| Lint / format | Biome |
| Package manager | Yarn |
| Container | Docker (`Dockerfile`, optional `docker-compose.yml`) |
