**[doubt-bot](https://github.com/Doubt-Productions/doubt-bot)** uses **PostgreSQL** through **Prisma 6**. Schema: `prisma/schema.prisma`. Generated client output: `src/generated/prisma`.

```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

Runtime and CLI both read **`DATABASE_URL`**.

## Connection

- Singleton Prisma client in `src/utils/prisma.ts`
- Graceful shutdown closes connections from `src/main.ts`

## Migrations (production)

Use the migrate workflow — **not** `db push` in production:

```bash
yarn prisma:generate
yarn prisma:migrate:dev      # local schema changes
yarn prisma:migrate:deploy   # staging/production
yarn prisma:migrate:status
```

<Note>
Legacy Doubt-Discord-Bot used MongoDB with `prisma db push`. doubt-bot uses versioned SQL migrations under `prisma/migrations/`.
</Note>

Optional local experiments only:

```bash
yarn prisma:push
```

Browse data:

```bash
npx prisma studio
```

## Models

### User

Discord users in Postgres (badges and XP relations).

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Primary key |
| `discordId` | String | Unique Discord snowflake |
| `username` | String | Last known username |
| `language` | String | Default `nl` |
| `createdAt` / `updatedAt` | DateTime | Timestamps |

Relations: `badges` → `UserBadge`, `xp` → `Xp`

---

### Badge

Global badge definitions.

| Field | Type | Description |
|-------|------|-------------|
| `key` | String | Primary key (e.g. `bot-staff`) |
| `displayName` | String | Shown name |
| `emoji` | String? | Optional emoji |
| `reserved` | Boolean | `true` for system badges |

Reserved **`bot-staff`** is ensured on ready via `ensureReservedBadges()`.

---

### UserBadge

Grants linking users to badges (display only for staff badge).

| Field | Type | Description |
|-------|------|-------------|
| `userId` | String | FK → `User` |
| `badgeKey` | String | FK → `Badge` |
| `grantedAt` | DateTime | When granted |

Unique on `(userId, badgeKey)`.

---

### BotStaff

Global staff **ACL** — one row per staff Discord user.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Primary key |
| `discordId` | String | Unique Discord user ID |
| `addedBy` | String | Developer Discord ID |
| `addedAt` | DateTime | When added |

Used by `/botstaff` and `StaffOnly` guards.

<Warning>
Run **`yarn prisma:migrate:deploy`** before creating BotStaff rows or running `/botstaff`. An empty table means staff-only commands fail closed.
</Warning>

---

### BotStaffRemoval

Audit trail when staff are removed.

| Field | Type | Description |
|-------|------|-------------|
| `discordId` | String | Unique removed user |
| `removedBy` | String | Developer ID |
| `removedAt` | DateTime | Removal time |

---

### Setup

Per-guild ticket (and automod-related) configuration.

| Field | Type | Description |
|-------|------|-------------|
| `guildId` | String | Unique guild |
| `ticketChannelId` | String? | Panel channel |
| `ticketCategoryId` | String? | Ticket category |
| `ticketStaffRoleId` | String? | Support role |
| `ticketLogChannelId` | String? | Optional log channel |
| Automod fields | various | Stored for future automod port |

---

### EconomyAccount

| Field | Type | Description |
|-------|------|-------------|
| `guildId`, `discordId` | String | Unique pair |
| `wallet`, `bank` | Decimal | Balances |

---

### Xp

| Field | Type | Description |
|-------|------|-------------|
| `guildId`, `userId` | String | Unique pair (`userId` → `User.id`) |
| `amount` | Int | XP total |
| `level` | Int | Current level |

---

### Afk

| Field | Type | Description |
|-------|------|-------------|
| `guildId`, `discordId` | String | Unique pair |
| `reason` | String? | AFK message |
| `nickname` | String? | Stored nickname to restore |

---

### WelcomeConfig

| Field | Type | Description |
|-------|------|-------------|
| `guildId` | String | Unique guild |
| `channelId` | String? | Welcome channel |
| `message` | String? | Template with placeholders |
| `rulesChannelId` | String? | Rules channel |
| `memberRoleId` / `botRoleId` | String? | Auto-roles |
| `welcomeRoleIds` | String[] | Extra role IDs |

---

### JtcSetup & JtcChannel

Join-to-create hub configuration and active temporary channels (`setupId`, `channelId`, `ownerId`).

## Legacy Mongo collections

[Doubt-Discord-Bot](https://github.com/Doubt-Productions/Doubt-Discord-Bot) used Mongo collections such as `ecoschemas`, `botstaff`, `welcomes`, `tickets`, `jtcsetups`. The **`yarn migrate:mongo`** tool maps them into the Postgres models above. Inert legacy data (e.g. old `guildschemas`) is skipped or reported in the migrator summary.

## Import paths

Application code imports Prisma via `src/utils/prisma.ts` and generated types from `src/generated/prisma` — not the old `src/schemas/*.js` re-export pattern from the JS bot.
